# Data-Visualization-Techniques

Data processing & visualization on the **Automobile Market Analytics** dataset using three data-mining
process frameworks: **CRISP-DM**, **SEMMA**, and **KDD**.

## Dataset
[Automobile Market Analytics Dataset](https://www.kaggle.com/datasets/deeplumiere/automobile-market-analytics-dataset) (Kaggle)

## Contents
- `Automobile_Market_Analytics_CRISPDM_SEMMA_KDD.ipynb` — main notebook, applies all three frameworks
  to the same dataset and compares them at the end.

## How to run
1. Download the dataset CSV from Kaggle and place it in this folder.
2. Update the `DATA_PATH` variable in the notebook's first code cell to match the file name.
3. `pip install -r requirements.txt`
4. Open the notebook in Jupyter and run all cells.
